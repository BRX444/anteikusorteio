# ANTEIKU · Sorteador de Brawl Stars

Sorteador de jogadores para Brawl Stars com tema Tokyo Ghoul.

## Funcionalidades
- Sorteio de **ganhadores** (escolha quantos)
- Divisão em **times**: Duo, 3v3 ou 5v5
- Animação de suspense **"1000 − 7"** (opcional)
- Efeitos sonoros (podem ser desligados)
- Remover nomes repetidos, copiar resultado e histórico dos últimos sorteios
- Atalhos: `Ctrl + Enter` sorteia, `Esc` fecha o resultado

## Como usar
Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicar no GitHub Pages
1. Envie os arquivos para um repositório.
2. Vá em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO`.
